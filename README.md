# 🎓 Student Performance Analysis 📊

## 📌 Project Overview
The **Student Performance Analysis** project aims to analyze academic performance of students and identify key factors that influence their exam scores.  
Using **Python and Data Science techniques**, this project explores how demographic, socio-economic, and academic preparation factors impact student outcomes.

---

## 🎯 Objectives
- Analyze student performance in **Math, Reading, and Writing**
- Understand the impact of:
  - Gender
  - Test preparation
  - Parental education
  - Lunch type
- Visualize trends and patterns in student scores
- Draw meaningful insights from the data

---

## 📂 Dataset Description
- **Dataset Name:** Students Performance in Exams
- **Source:** Kaggle
- **Records:** 1000 students
- **Features:**
  - Gender
  - Race/Ethnicity
  - Parental level of education
  - Lunch type
  - Test preparation course
  - Math score
  - Reading score
  - Writing score

---

## 🛠 Tools & Technologies Used
- **Programming Language:** Python
- **Libraries:**
  - Pandas
  - NumPy
  - Matplotlib
  - Seaborn
- **Environment:** Jupyter Notebook

---

## 🔍 Project Workflow
1. Data Loading and Inspection  
2. Data Cleaning and Preprocessing  
3. Feature Engineering (Average Score Calculation)  
4. Exploratory Data Analysis (EDA)  
5. Data Visualization  
6. Insights and Conclusions  
7. (Optional) Simple Machine Learning Model  

---

## 📊 Key Analysis Performed
- Gender vs Student Performance  
- Test Preparation vs Average Score  
- Parental Education vs Student Performance  
- Lunch Type vs Academic Results  
- Subject-wise Score Distribution  
- Correlation Analysis between Subjects  

---

## 📈 Key Insights
- Students who completed the **test preparation course** performed better on average.
- **Standard lunch** students showed higher performance compared to free/reduced lunch students.
- **Reading scores** were generally higher than Math scores.
- Parental education level positively influences student performance.
- Math was identified as the most challenging subject for many students.

---

## 🤖 Machine Learning (Optional)
- A **Linear Regression model** was used to predict the average score based on:
  - Gender
  - Lunch type
  - Test preparation
- The model demonstrated a reasonable prediction accuracy for a beginner-level project.
